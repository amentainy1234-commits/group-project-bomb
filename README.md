# 조별과제 폭탄돌리기

로그인이나 서버 없이 바로 쓰는 정적 웹사이트입니다. 팀원 이름과 역할은 브라우저 안에서만 처리되며 저장되거나 전송되지 않습니다.

## 바로 확인하기

`index.html` 파일을 더블클릭해 브라우저에서 엽니다. Node.js나 별도 패키지 설치 없이 작동합니다.

## 무료로 웹에 공개하기

1. GitHub에 `group-project-bomb`라는 **공개 저장소**를 만듭니다. README 자동 추가는 선택하지 않습니다.
2. 이 폴더의 `index.html`, `styles.css`, `script.js`를 저장소 최상단에 올립니다.
3. 저장소의 **Settings → Pages**로 들어갑니다.
4. **Deploy from a branch**를 선택하고 `main` 브랜치의 `/ (root)` 폴더를 고른 다음 저장합니다.
5. 잠시 뒤 표시되는 `https://계정이름.github.io/group-project-bomb/` 주소로 접속합니다.

GitHub Pages 무료 사용은 공개 저장소가 필요합니다. 사이트 소스가 공개되지만, 방문자가 입력한 팀원 이름과 결과는 사이트로 전송되지 않습니다. 인터넷 주소는 무료 기본 주소를 쓸 수 있고, 원하는 도메인을 따로 구매하는 건 선택 사항입니다.

## 기능

- 팀원과 역할 추가·삭제
- 추천 역할 여러 개 선택 후 한 번에 추가
- 이름 수 확인, 중복 역할 방지 및 중복 검사
- 역할을 섞어 한 사람당 하나씩 배정
- 결과 복사, 다시 섞기, 초기화
